# Penny Beta 1.0.2

- **Instant page switching.** Moving between pages no longer rebuilds them from scratch. Going back to a page you just left shows it immediately, at the same scroll position, with no reload flash. Penny still redraws a page whenever your data, language, filters or the date have changed, so what you see is always current.
- **Faster Overview and Insights.** Insights are now worked out once per change instead of several times per screen, so the Overview, Insights page and the sidebar badge update with less work.
