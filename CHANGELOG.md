# Changelog

Full notes for each version are in [docs/releases](docs/releases/) and on [GitHub Releases](https://github.com/abdallhhelles/penny/releases).

Version numbers restarted at **1.0.0** for the first public beta. Everything before it (1.7 to 1.11) was early access.

## Public beta
| Version | Highlights |
|---|---|
| [1.0.7](docs/releases/RELEASE-1.0.7.md) | Penny Research: re-based Financial Health Report, fairer scores, new measures, one set of targets everywhere; chart, plan and budget fixes |
| [1.0.6](docs/releases/RELEASE-1.0.6.md) | First five minutes: start from a bank statement, drop files anywhere, an import summary, no empty dashboard |
| [1.0.5](docs/releases/RELEASE-1.0.5.md) | Privacy mode hides every number, Excel export, accent colours, Penny Pro preview, shared core |
| [1.0.4](docs/releases/RELEASE-1.0.4.md) | US bank and Mint/YNAB/Monarch imports, clean payee names, card payments as transfers, Rate Penny |
| [1.0.3](docs/releases/RELEASE-1.0.3.md) | Desktop widget, achievements and streaks, remembered choices, layout at every window size |
| [1.0.2](docs/releases/RELEASE-1.0.2.md) | Instant page switching, faster Overview and Insights |
| [1.0.1](docs/releases/RELEASE-1.0.1.md) | Tailored tour, smarter Ask Penny, payee memory, no notification spam, Microsoft Store ready |
| [1.0.0](docs/releases/RELEASE-1.0.0.md) | Beta 1: Penny in five languages, typing in your own language, translated installer |
